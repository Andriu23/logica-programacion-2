# 🌡️ Conversión de Temperaturas

## 📌 Descripción
Este proyecto consiste en una aplicación web que permite convertir una temperatura ingresada en grados Celsius a grados Fahrenheit y Kelvin. También valida los datos ingresados y muestra los resultados con colores dinámicos según la temperatura.

## 🎯 Objetivo
Practicar el uso de HTML, CSS y JavaScript para crear una interfaz interactiva, realizar operaciones matemáticas y manipular elementos del DOM.

## 🛠️ Tecnologías utilizadas
- **HTML5:** estructura de la página.
- **CSS3:** estilos, diseño adaptable y colores dinámicos.
- **JavaScript:** validación de datos, cálculos y manipulación del DOM.
- **Bootstrap 5:** estilos para los resultados y componentes visuales.

## ⚙️ Funcionalidades
- Ingresar una temperatura en grados Celsius.
- Convertir Celsius a Fahrenheit y Kelvin.
- Validar que el valor ingresado sea numérico.
- Mostrar los resultados sin duplicar los anteriores.
- Cambiar los colores según la temperatura:
  - 🔵 Azul: menos de 10 °C.
  - 🟡 Amarillo: entre 10 °C y 25 °C.
  - 🔴 Rojo: más de 25 °C.
- Adaptar la interfaz a diferentes tamaños de pantalla.

## 🧮 Fórmulas utilizadas

**Celsius a Fahrenheit:**

°F = (°C × 9 / 5) + 32

**Celsius a Kelvin:**

K = °C + 273.15

## 🚀 Cómo ejecutar el proyecto
1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en el navegador, preferiblemente con la extensión Live Server.
4. Ingresar una temperatura en Celsius y hacer clic en **Convertir a °F y Kelvin**.

## 📚 Aprendizajes
Esta actividad permite practicar eventos en JavaScript, validación de datos, operaciones matemáticas, creación de elementos HTML mediante el DOM, uso de clases de Bootstrap y aplicación de estilos CSS.
